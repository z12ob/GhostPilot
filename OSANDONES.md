# Osandones protected component

This repository publishes the interface for `ghostpilot`. Its implementation is distributed separately after Osandones confirms the exact purchase and signed permission for the exact commit being used.

- Public module: `src/ghostpilot.js`
- JavaScript format: `CommonJS`
- Export: `ghostpilot`
- Requested use: `commercial-integration`
- Authoritative policy: `https://app.osandones.com/api/v1/rights?repository=z12ob%2Fghostpilot&use=commercial-integration`

The file `.osandones/policy.json` is a discovery pointer, not a license or a secret. Purchased implementations are installed under `.osandones/implementation/`, which is excluded from Git by the nested ignore rule.
